## Entrega
Ação da retrospectiva da Sprint 12: o executor e o passo a passo ficavam no scratchpad e se perderam numa limpeza do `/tmp`.
- `docs/insomnia/executar.mjs` (versionado): roda a exportação v4 reproduzindo os scripts `insomnia.*`, com `PULAR=` para pular pastas.
- `scripts/rodar_collection.sh`:
  - sobe a API numa porta livre, nunca a 8000, com banco SQLite e uploads temporários;
  - roda o seed de desenvolvimento e monta as variáveis num arquivo temporário (`umask 077`), apagado no fim;
  - executa a collection e para a API no `trap`, inclusive quando falha.
  - A API roda com `ONECHECK_SEM_DOTENV=1`, novo em `app/config.py`, e não lê o arquivo de configuração local. Tudo o que ela usa (banco, segredos, uploads) vem do script.
- **Collection ajustada ao SEC-027:** o caso "reusar o refresh já trocado" encerra todas as sessões do admin, então a collection agora confere que a sessão foi encerrada e faz login de novo. A regressão estava na collection, não na API, e apareceu na primeira rodada do comando.
